# Terroir Terre Authentique

Site vitrine en français présentant des produits du terroir, le savoir-faire local et un formulaire de contact.

## Contenu

- `index.html` : structure de la page (navigation, présentation, produits, terroir et contact).
- `style.css` : styles personnalisés du site.
- `image/` : images des produits.

## Lancer le site

Ouvrez `index.html` dans un navigateur. Bootstrap, Font Awesome et les polices Google sont chargés depuis des CDN ; une connexion Internet est nécessaire pour ces ressources.

## Cartes des produits

Les cartes utilisent la grille responsive de Bootstrap : une colonne sur petit écran, deux sur écran moyen et trois sur grand écran. Les images gardent une hauteur uniforme et les boutons sont alignés au bas des cartes.
